Claude 启动动画（照抖音「Codex 启动动画」的效果做的）
=====================================================

【怎么用】
双击桌面上的「Claude」图标：先播约 12 秒的启动动画，同时在后台打开 Claude，
动画播完、Claude 窗口也出来了，动画就淡出，露出 Claude。
不想等：在动画上点一下鼠标，马上跳过。

【动画流程】（照抖音「倾城丨奈何 · Codex启动动画」的节奏，约 12 秒）
0~0.8 秒  黑屏
0.8~3.6 秒 图片从头顶往下变成霓虹线条一笔笔描出来（左边偏蓝、中间偏紫、右边金黄），
          左边灰色代码一行行打出来、往上滚，细长光带横扫、蓝紫黄的流星往下落
1.8~5 秒  脸上浮出一层白色三角网格（像在扫描建模）
2.4~4.8 秒 人物先暗暗透出来，再变成全彩（这时还闭着眼）；上色的同时把「人物以外」的地方压暗七成（星空、星云基本压黑），
          人物本身保持原来的亮度；所以流星、光弧的光更显眼。流星 28 颗、头上带一粒发光的光点，光弧加粗
5.6~7.35 秒 一口气连贯睁开，共 1.75 秒（13 个开合程度 0%→8%→…→100% 平滑过渡）：慢慢起步，中间匀速，最后轻轻停住
          眼睛的光跟着睁开一路变亮：刚睁一条缝时是贴着眼缝的一道扁光，睁多少亮多少、越睁越高越亮，全开前已到七成半
7.35~8.0 秒 完全睁开的那一下：眼珠上炸开明亮的蓝白光（光晕往外胀一下 + 一道横光从眼珠划开），之后退成明显的光一直留着
7.37~8.4 秒 同一刻从两只眼睛放出一道淡蓝色的光晕，沿着人物向四周扩散：先扫过脸和刘海，再到头饰、头发、肩、领结、发梢，
          扫到哪里哪里被照亮、霓虹线条跟着亮一下，边扩边淡；只照人物，人物以外基本不照。扫完后画面跟没有光晕时一模一样
          眼睛是画面里最亮的地方：眼珠本身提亮一层（花纹还在）、周围洒一圈淡蓝光到脸上
8.0~9.4 秒 代码慢慢淡出，只剩人物
8.6 秒    左边亮起大标题「Claude」（蓝紫金渐变、发光，一道光扫过），正下方居中一行「欢迎主人回家」
10.1 秒   再下面浮出一行慢慢呼吸的「按任意键进入」
之后     一直停在这一幕，按任意键才淡出进入（按的时候 Claude 还没打开，就显示「正在唤醒」等它，最多等 25 秒）

【想调明暗】（改 ClaudeSplash.cs 里的数，再运行 build.ps1 重新编译）
- 人物以外压多暗：DimBack（现在 0.72；0 = 不压，1 = 全黑）。哪里算「人物」看「人物蒙版.png」（白 = 人物，黑 = 人物以外）
  （删掉「人物蒙版.png」就变成整张图一起压暗、只有眼睛不压：那时用 DimBase 0.34、DimEdge 0.30）
- 睁眼多久：EyeOpenStart / EyeOpenEnd（现在 5.6 → 7.35，共 1.75 秒）
- 眼睛的光：找「光晕」「亮光芯」「横光」「洒到脸上的光」几段，Color.FromArgb 的第一个数是浓度（0~255）
- 睁眼过程中光亮得多快：Update 里 eg / core / spill 三行，kOpen 前面的数越大 = 睁眼途中越亮（现在 0.75 / 0.65 / 0.6）
- 扩散的光晕：WaveDur（整个过程多少秒，现在 1.7，越大扩得越慢）、WaveOutside（人物以外照到多少，现在 0.07）、
  WaveTint（光的颜色）；MakeLit 里的 0.38 是光的浓度；不想要光晕就把 WaveDur 改成 0.001

【换图】
- 把想要的图放进这个文件夹，改名「图片.png」（或 .jpg）覆盖掉就行，不用重新编译
- ★换图时把「人物蒙版.png」「睁眼帧」「眼睛.txt」一起删掉或换掉：它们都是照现在这张图做的，留着会对不上
  （新图想要「只压暗人物以外」：python make_character_mask.py 图片.png 人物蒙版.png）
- 横图会铺满整个窗口；竖的人物图会贴在右下角；暗色背景、人物偏右的图效果最好
- 删掉「图片.png」就回到 Claude 星芒版
- 「备用图片」文件夹里放着以前试过的紫发少女

【壁纸（默认关着）】
动画播完后，也可以让这张图压暗后一直贴在 Claude 窗口上当壁纸（鼠标能点穿）。
现在是关的。想开：在这个文件夹新建「设置.txt」，里面写一行「壁纸=开」。
开了以后右下角托盘会有个小图标，右键能调浓淡、隐藏、关掉。

【文件说明】
ClaudeSplash.exe         动画程序（桌面图标指向它）
ClaudeSplash.cs          源代码
build.ps1                改了源代码后，右键「使用 PowerShell 运行」重新编译
claude.ico               从 Claude 程序里取出来的图标
图片.png                 动画用的图
make_closed_eyes.ps1     以前试的「闭眼→眼皮抬起」用的脚本（已不用，相关图片在 备用图片\睁眼效果(不用了)）
眼睛.txt                 这张女仆图的眼睛位置，睁眼时眼睛的蓝光打在哪靠它（「瞳孔=」两行是两只眼珠的中心，光就打在那）；换了别的图（尺寸不同）会自动不用
retouch_eye_frames.py    修眼睛帧用的脚本（Python）：python retouch_eye_frames.py 原件文件夹 输出文件夹
人物蒙版.png             白 = 人物、黑 = 人物以外；程序只压暗黑的地方
make_character_mask.py   从图片自动抠出人物蒙版的脚本（Python）
修图前后对比\            13 张图修前/修后的对比图
原版Claude快捷方式.lnk   不要动画了：把它复制到桌面、改名「Claude」覆盖掉现在那个就行

【只看动画、不打开 Claude】
在这个文件夹的地址栏输入 cmd 回车，然后输入：ClaudeSplash.exe --preview（同样要按任意键才关）
